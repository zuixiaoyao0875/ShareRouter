# ShareRouter (分享路由)

ShareRouter 是一款专注于解决 Android 系统默认分享菜单“臃肿、不可搜索、无法排序、不能精简”痛点的极简实用工具。通过作为一个“二次转发中间层”，它接管了系统的分享意图（Intent），并提供了一个高度可定制的纯粹分享面板。

## ✨ 核心功能

1. **精准分享与搜索**：彻底告别在几十个图标里眼花缭乱地翻找。提供实时搜索栏，极速定位目标应用。
2. **“所见即所得”的面板定制**：
   - **动态网格（1~20列）**：支持将分享界面划分为最多 20 列的超密网格，或是退化为单列列表。
   - **自适应字号（1~24sp）**：根据您的网格列数，自由调节应用名称的大小。
   - **极限行间距控制**：采用无内边距（Padding-free）设计，配合行距滑块，实现像素级的排版控制。
   - **纯净模式**：一键隐藏应用名称，仅保留图标。
3. **应用分区与管理**：
   - **置顶与隐藏**：将高频应用置顶，对垃圾分享项进行永久隐藏。
   - **临时显形**：支持一键临时查看隐藏应用，单次分享后自动恢复隐藏。
4. **多维拖放排序中心**：将桌面主应用界面打造为“配置中心”。应用列表同步您的网格偏好，支持长按图标进行跨列、跨行的二维拖拽排序，手势丝滑，永久记忆。

## 🛠 开发流程回顾

本项目采用 Android 现代技术栈（Kotlin + Jetpack Compose）构建，整体经历了由简入深、反复推敲细节的渐进式开发过程：

1. **基础路由层搭建 (V1.0)**：
   - 确立以 `MainActivity` 作为 `ACTION_SEND` / `ACTION_SEND_MULTIPLE` 的唯一接收入口。
   - 利用 `PackageManager` 查询设备上所有支持分享的目标。
   - 编写 `forwardIntent` 方法，重写分享意图的 `ComponentName`，实现无缝的二次转发。
2. **交互雏形与管理逻辑 (V1.5)**：
   - 使用 Compose 引入底部半透明弹窗 (`ModalBottomSheet`)。
   - 通过 `SharedPreferences` 实现数据持久化，加入了“置顶集合”与“隐藏集合”的概念。
   - 引入了搜索过滤逻辑。
3. **动态网格与视觉革命 (V2.0)**：
   - 彻底废弃原本低效的单列 `LazyColumn`，引入 `LazyVerticalGrid`。
   - 内嵌动态控制台，引入 `Slider` 控制列数和名称显示。
   - 解决原生控件缩放时的“高度塌陷”死白问题，通过 `aspectRatio(1f)` 和取消字体默认内边距 (`includeFontPadding`) 达到了极致紧凑的视觉效果。
4. **拖拽效率升级 (V2.1)**：
   - 为了解决单列模式大跨度排序困难的问题，引入了业界最新的 `sh.calvin.reorderable` 拖放库。
   - 将主界面的配置中心升级为与分享面板一致的多维网格。
   - 通过 `longPressDraggableHandle` 解决滑动冲突，实现长按图标的极速多维重排。
4. **性能与健壮性里程碑 (V2.5)**：
   - **零掉帧加载方案**：引入“三段式阶梯载入”策略，将冷启动时的系统压力分摊到毫秒级的时间线上，彻底消除首帧卡顿。
   - **智能检索系统**：实现支持忽略特殊符号、自动跳过空格、支持多音字识别的拼音首字母搜索（T9 风格）。
   - **热更新快车道**：区分冷启动与交互场景，使隐藏、置顶等操作在热状态下实现瞬间刷新。
   - **配置迁移闭环**：通过 JSON 序列化实现了配置的导入导出，并配套二次确认弹窗，保障用户数据的可迁移性与安全性。

## 🚀 后续升级与优化方案

ShareRouter 的架构现已非常稳固，未来的演进将侧重于“智能化”与“极致感官”：

### 1. 上下文感知智能路由 (Context-Aware)
- **智能权重排序**：根据分享内容的 MIME 类型自动调整应用顺序。
    - 分享 `URL` -> 自动置顶 浏览器、电报。
    - 分享 `Image` -> 自动置顶 修图软件、社交平台。
    - 分享 `Text` -> 自动置顶 笔记软件、翻译工具。

### 2. 极致动效与感官增强 (Premium Motion)
- **非线性动画**：引入更细腻的列表重排动画、进入面板时的弹性缩放动效。
- **触感反馈**：在长按排序、点击隐藏等关键节点加入不同震感强度的触觉反馈。
- **Material You 深度融合**：跟随 Android 系统主题色动态调整 UI，加入磨砂玻璃（Blur）背景效果。

### 3. 生态与同步 (Ecosystem)
- **跨端云同步**：通过 WebDAV 或简单的私有云方案，实现多台安卓设备间的配置静默同步。
- **捷径与磁贴**：在系统控制中心增加一键呼出管理面板的快捷磁贴，或在桌面创建特定应用的分身入口。
