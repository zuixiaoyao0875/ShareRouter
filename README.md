## 📖 项目简介 (Chinese)

**ShareRouter** 是一款专为 Android 用户设计的分享管理利器。它作为系统分享菜单的“智能中转站”，不仅能帮你拦截并克隆分享内容，还能管理你的分享历史，让你随时找回并重新分发。

### ✨ 核心功能
- **分享历史克隆**：自动保存分享的文本、图片、视频及各类附件到应用私有目录。
- **深度元数据追踪**：记录分享的来源应用（如：来自微信、文件管理）、原始文件名及精确的 MIME 类型。
- **个性化菜单定制**：支持长按置顶常用应用，或隐藏不常用的分享目标，让分享列表更干净。
- **快速重新分发**：在历史记录中一键唤起系统分享，将内容二次转发给其他应用。
- **配置导入导出**：轻松迁移你的应用偏好设置与隐藏列表。
- **现代 UI 设计**：基于 Jetpack Compose 与 Material 3 构建，支持灵动动画与沉浸式状态栏。

## 📖 Introduction (English)

**ShareRouter** is a sophisticated sharing management utility for Android. Acting as an "intelligent proxy" for the system share menu, it enables you to intercept, clone, and manage sharing events, ensuring you can always retrieve and redistribute past content.

### ✨ Key Features
- **Share Cloning**: Automatically persists shared text, images, videos, and multiple attachments to private storage.
- **Rich Metadata Tracking**: Identifies source applications (e.g., from WeChat, File Manager), preserves original filenames, and captures precise MIME types.
- **Menu Customization**: Pin your favorite apps or hide unwanted targets with simple long-press interactions for a clutter-free experience.
- **Instant Redistribution**: Re-trigger share intents directly from history to dispatch content to other apps.
- **Config Portability**: Seamlessly export/import your app preferences and hidden lists.
- **Modern UI**: Built with Jetpack Compose and Material 3, featuring fluid animations and edge-to-edge design.
